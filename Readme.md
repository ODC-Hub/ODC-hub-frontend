# ODC Hub Frontend

### Bootcamp Management Platform — Frontend Application

Frontend application for the **ODC Hub platform**, providing a modern admin-style interface to manage users, dashboards, and workflows for bootcamp programs.

Built with **React and TypeScript**, the application focuses on **security, scalability, and clean UI architecture**, and communicates with the backend through secure REST APIs.

---

## Key Features

- Secure authentication using **JWT via HttpOnly cookies**
- Role-based access and protected routes
- Admin dashboards and user management views
- Modular and reusable UI components
- Responsive layout suitable for internal platforms

---

## Business Value

- Centralizes bootcamp operations in a single interface
- Improves administrative efficiency and user supervision
- Provides a scalable frontend foundation for multiple programs

---

## Technical Highlights

- Clean React architecture with reusable components
- Global state management using Context API
- Secure API communication using Axios with credentials
- Route protection and authentication guards
- Modern styling with Tailwind CSS

---

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **State Management**: Context API
- **Routing**: React Router
- **HTTP Client**: Axios
- **Authentication**: JWT (HttpOnly cookies)

---
